# Savant Synesthetic Agent 🧠✨

### 🇨🇱 Project for the Gemini Live Agent Challenge

**Savant Synesthetic Agent** is a specialized cognitive partner designed for neurodivergent adults (Late-identified Autism, ADHD, and Synesthesia).

## 🚀 Vision
The goal is to move from a "deficit-based" view of neurodivergence to a "talent-based" mapping. The agent uses high-resolution data from synesthetic perceptions to identify professional and creative strengths.

## 🛠️ Technology Stack
* **Model:** Gemini 2.0 Flash
* **Platform:** Google AI Studio / Google Colab
* **Reasoning Framework:** Bayesian updating for self-perception.

## 📁 Repository Content
* `Savant_Agent.ipynb`: Core logic and System Instructions.
* `Project_Presentation.pdf`: Detailed research and concept documentation.
